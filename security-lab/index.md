# Isolated Web Security Lab

## Overview

I'm building an isolated cybersecurity lab to develop practical
experience with network security, web application security,
Linux administration, exploitation, and system hardening.

The goal is to create a controlled environment where I can safely
experiment with security concepts and document what I learn.

## Lab Environment

| System | Purpose |
|---|---|
| Alpine Linux | Security workstation |
| Debian | Server |
| Metasploitable 2 | Intentionally vulnerable target |
| VMware | Virtualization |
| Dedicated M.2 SSD | VM storage |

## Project Goals

- Network enumeration
- Web application security
- Authentication and authorization
- Vulnerability exploitation
- Linux privilege escalation
- System hardening
- Security documentation
